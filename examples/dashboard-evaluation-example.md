# Example: evaluating hierarchy in a dashboard

> Didactic example. Does not represent data from a real product.

## Scenario

A dashboard presents 18 indicators with the same visual weight. There is no visible selected period, unit on some charts, or indication of which numbers require action.

## Diagnosis

1. **Insufficient hierarchy:** the person cannot distinguish critical information from context.
2. **Incomplete context:** values without period, unit or comparison can induce wrong interpretations.
3. **Unclear action:** the panel shows numbers but does not help identify the next step.

## Related concepts

- Prägnanz and Gestalt grouping.
- Cognitive load.
- Visibility of system status.
- Recognition rather than recall.

## Recommendations

- Group indicators by decision or task.
- Show period, unit, source and comparison.
- Differentiate outcome, diagnostic and operational metrics.
- Highlight exceptions only when there is an explicit criterion.
- Do not use color as the only meaning channel.
- Allow access to detail without overloading the initial view.

## Validation

Ask representative users to answer real questions using the dashboard. Measure accuracy, time, interpretation errors and confidence. Compare with the previous version.
